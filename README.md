## 四、 作業問題回答

### 問題一：為什麼 "4" 要先轉成數字，才能用於本題的分攤計算？
**回答：**  
因為 `"4"` 在 Python 中是字串型別（`str`），字串無法直接參與數學除法運算（例如總金額除以 `"4"` 會引發 `TypeError` 型別錯誤）。必須先透過 `int()` 函式將其轉換為整數（`int`），才能正確計算出每人應付的費用。

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？
**回答：**  
* **計算結果：** 若先扣折價券再算 10% 服務費，總額會變成 $(1,200 - 100) \times 1.1 = 1,210$ 元。
* **原因說明：** 這與題目規定的 1,220 元不同，是因為「服務費的計算基準」改變了。照原題目規則，服務費應該根據餐廳提供的原始餐費（1,200 元）全額計算（$1,200 \times 0.1 = 120$ 元），折價券則是在服務費加總後才抵扣；若先扣折價券等於讓折價券也享有免服務費的折抵，導致計算邏輯不符餐廳規定。
